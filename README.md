# municipality-silhouette

市区町村のシルエットを見て名前を当てるゲームの練習をかねた個人試作（パクリ元→https://shikuchoson.jp/）。
静的ファイルだけで動くので、GitHub Pages にそのまま載せられる構成にしてある。

## 遊び方

```
npm run serve        # http://localhost:8000/ を開く
```

- シルエットを見て市区町村名を入力する。チャンスは6回
- 漢字・ひらがな・カタカナどれでもよく、「市」「町」などや都道府県名は付けても付けなくてもよい（例：横浜市／よこはま／神奈川県横浜市）
- 存在しない名前は回数に数えない。同じ名前が複数ある場合（府中市など）は、どれかが正解なら正解
- 今日の問題は日付（日本時間）で決まり、途中経過はブラウザに保存される。終わったら「もう一問」で練習問題を出せる
- 北方領土の6村は答えにしない

## データの作り方

```
npm install
npm run fetch        # raw/ に元データを取得（約770MB、commitしない）
npm run build:data   # data/ を作り直し、総務省一覧との過不足・読み・頂点数・サイズを検証する
npm run serve        # http://localhost:8000/check.html で形を確認
```

加工はすべて手元で行い、サーバーには出来上がった画像と一覧だけを置く。加工は4段階（`scripts/build.sh`）。

1. `dissolve.sh`：N03を市区町村単位にまとめる。政令市は区を結合して1市にする（20市のコード表と照合し、合わない区があれば失敗）。所属未定地は除く
2. `build-data.mjs`：出題用の形（中間ファイル `raw/build/shapes/`、commitしない）と一覧を作る
   - 面積0.01km²未満の小島を除く（唯一の陸地なら残す）
   - 表示枠：最大の陸地と、そこから50km以内かつ面積が1%以上の島
   - 間引き：表示枠の対角線の1/15000より小さい凹凸を消す（大きさに比例。画像側より細かくしておく）
3. `render-images.mjs`：形を表示枠に合わせて投影し、画像 `data/images/<code>.svg` にする。間引きは画像上で0.1px（1000px四方）。細かさはこれで決まり、`TOL=0.05 npm run build:data` のように実行時に変えられる
4. `build-japan.sh`：答え合わせ用の全国地図（境界線を共有したまま800m単位で間引く）

基準値は `build-data.mjs` と `render-images.mjs` の冒頭にまとめてある。

## 出力

| ファイル | 内容 |
| --- | --- |
| `data/index.json` | コード・名前・都道府県・読み（カタカナ）・代表点・表示枠 |
| `data/images/<code>.svg` | 出題用の形の画像（1件1ファイル。`<img>` で表示するだけ） |
| `data/japan.topojson` | 全国地図（市区町村と都道府県） |

- 基準日：2026年1月1日（N03）
- 件数：1,747（1,718市町村 + 東京23区 + 北方領土6村）

## 読みの修正

読みは総務省の一覧のカタカナを使う。直したい場合は `data/kana-overrides.csv` に行を足して `npm run build:data` を再実行する。

```
code,kana,note
39405,ユスハラチョウ,例：修正理由をメモ
```

存在しないコードやカタカナ以外の読みは、加工時に失敗する。
